What is a Queue?

A queue follows First-In-First-Out (FIFO) ordering. Like a line at a ticket counter — the first person in line is served first.

Operations

  1. Enqueue(x) — add to rear — O(1)
  2. Dequeue() — remove from front — O(1)
  3. Front()/Peek() — view front element — O(1)

FAQ

Where are queues used?

Task scheduling, BFS traversal, printer spooling, message queues (Kafka, RabbitMQ), and buffering.

What is a Circular Queue?

A queue where the rear wraps around to the front when full, avoiding wasted space in array implementations.
