HEX vs RGB vs HSL in CSS

HEX is compact for web assets. RGB expresses red, green, and blue primary color channels (0-255). HSL (Hue, Saturation, Lightness) provides an intuitive human model for adjusting shades, tints, and gradients easily.

Frequently asked questions

What is HSL Hue range?

Hue is measured in degrees on the color wheel from 0 to 360 (0° = Red, 120° = Green, 240° = Blue).
