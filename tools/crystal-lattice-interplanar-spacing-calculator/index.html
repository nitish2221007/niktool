How to use Crystal Lattice Interplanar Spacing (d_hkl) Calculator

  1. Enter cubic crystal unit cell lattice parameter a in Ångströms (1 Å = 0.1 nm = 10⁻¹⁰ m).
  2. Enter integer Miller indices (h, k, l).
  3. Inspect perpendicular distance between parallel atomic lattice planes in Ångströms and nanometers.

William Hallowes Miller's 1839 Index System

Miller indices uniquely define the spatial orientation of atomic planes in a crystalline solid; for FCC metals (like Gold and Copper), the (111) planes have the widest spacing and highest atomic packing density.

Frequently asked questions

What is the d-spacing for (111) planes in Copper (a = 3.615 Å)?

d₁₁₁ = 3.615 / √(1² + 1² + 1²) = 3.615 / √3 ≈ 2.087 Ångströms.
