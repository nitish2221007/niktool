What is Recursion?

Recursion is when a function calls itself with a smaller sub-problem until it reaches a base case. Every recursive call is pushed onto the call stack.

Key Concepts

  1. Base case — the condition that stops recursion
  2. Recursive case — the function calling itself with smaller input
  3. Call stack — each call creates a new stack frame

FAQ

Why is naive Fibonacci O(2ⁿ)?

fib(n) calls fib(n-1) and fib(n-2), causing overlapping sub-problems. The call tree doubles in width at each level.

How to optimize recursive Fibonacci?

Use memoization (top-down DP) to cache results, reducing time to O(n).
