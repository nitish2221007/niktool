Percentage Change Formula

Percentage change represents the relative difference between an original value and a new value: Change (%) = ((V2 - V1) / |V1|) × 100. If the result is positive, it is a percentage increase; if negative, a percentage decrease.

Private browser-based processing

All calculations and conversions run 100% locally in your browser. No personal data or numbers are ever transmitted or saved to external servers.
