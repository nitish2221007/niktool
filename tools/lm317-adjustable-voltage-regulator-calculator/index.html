1.25V Internal Bandgap Reference

The LM317 maintains a precision 1.25V reference between its OUT and ADJ pins, establishing a constant 5.2 mA programming current across R₁ that flows through R₂ to set the stable output voltage.

Frequently asked questions

How do you configure an LM317 for 5.0V output with R₁ = 240Ω?

R₂ = R₁ · (V_out / 1.25 - 1) = 240 × (5.0 / 1.25 - 1) = 240 × 3 = 720 Ω.
