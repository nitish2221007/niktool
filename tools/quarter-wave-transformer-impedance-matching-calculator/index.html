How to use Quarter-Wave Transmission Line Impedance Matching (Z₀ = √(Z_in·Z_L)) Calculator

  1. Enter source generator input transmission line impedance $Z_{ ext{in}}$ in Ohms (typically 50 Ω).
  2. Enter load antenna / device real termination impedance $Z_L$ in Ohms.
  3. Enter RF operating carrier frequency in GHz.
  4. Enter substrate PCB dielectric constant $epsilon_r$ (4.4 for FR4, 3.48 for Rogers RO4350B).

Narrowband Transmission Line Impedance Matching

At quarter-wavelength electrical length ($ heta = pi/2$), destructive interference cancels reverse reflections at the input interface ($Z_{ ext{in}} = Z_0^2 / Z_L$), transferring 100% of RF microwave power into the load with zero reflected power ($Gamma = 0$).

Frequently asked questions

Can a quarter-wave transformer match complex reactive impedances (R + jX)?

No, quarter-wave matching requires real impedances; a series transmission line spacer or shunt stub must first be added to cancel the reactive $+jX$ component.
