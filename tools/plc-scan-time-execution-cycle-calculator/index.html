The Read-Execute-Write PLC Operating Cycle

PLCs execute cyclically: 1) Read physical inputs into the process image table, 2) Execute ladder logic sequentially, 3) Write output coils, and 4) Service communications; any physical digital sensor pulse shorter than $2 imes T_{ ext{scan}}$ risks being skipped entirely.

Frequently asked questions

How do PLCs handle high-speed encoder pulses faster than the scan time?

High-speed encoder signals bypass the main scan cycle by using dedicated hardware High-Speed Counter (HSC) and interrupt subroutines.
