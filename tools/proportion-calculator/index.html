How to use Proportion Calculator

  1. Enter four values for a : b = c : d, using x (or a blank) for the unknown.
  2. Click Process to solve the missing value.
  3. Follow the cross-multiplication steps shown in the result.

Key Features & Privacy

The tool applies the proportion rule a x d = b x c, isolates the unknown, and shows the exact substitution so you can verify each step. It validates against division by zero and runs entirely in your browser.

Common Use Cases

Students use it to solve proportion word problems, unit-rate questions, and similar-triangle side calculations in Class 10 maths.
