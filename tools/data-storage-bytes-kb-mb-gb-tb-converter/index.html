Why 1 TB Hard Drives Show as 931 GB in Windows

Hard drive manufacturers sell storage in decimal SI units (1 TB = 10¹² Bytes), but Windows displays storage in binary gibibytes (1 GiB = 2³⁰ Bytes), causing 1,000,000,000,000 Bytes / 1,073,741,824 = 931.32 GiB.

Frequently asked questions

What is 1 Gigabyte vs 1 Gibibyte?

1 GB is 1,000,000,000 Bytes (10⁹), whereas 1 GiB is 1,073,741,824 Bytes (2³⁰).
