BFS vs DFS on a Grid

  1. BFS explores outward uniformly — guarantees shortest path on unweighted grids.
  2. DFS dives deep along one branch before backtracking — faster but no shortest-path guarantee.

FAQ

Why is BFS better for shortest path?

BFS explores all cells at distance d before any at distance d+1, so the first time it reaches the target is via the shortest path.
