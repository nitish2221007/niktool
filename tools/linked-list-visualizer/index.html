What is a Linked List?

A linked list is a linear collection of nodes where each node stores data and a pointer to the next node. Unlike arrays, elements are not stored contiguously in memory.

Operations Complexity

  1. Insert at head — O(1)
  2. Insert at tail — O(n) without tail pointer, O(1) with
  3. Delete — O(n) to find, O(1) to unlink
  4. Reverse — O(n) time, O(1) space

FAQ

Linked List vs Array?

Arrays give O(1) random access but O(n) insertion. Linked lists give O(1) insertion/deletion at known positions but O(n) access.
