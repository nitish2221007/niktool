Why Remove Zero-Width Spaces?

Invisible characters copied from PDFs or rich-text websites can cause mysterious syntax bugs in Python, JSON, SQL parsers, and regex matchers. Removing them ensures clean compile and runtime execution.

Private browser-based processing

All calculations and conversions run 100% locally in your browser. No personal data or numbers are ever transmitted or saved to external servers.

Frequently asked questions

What is Unicode U+200B?

U+200B is the standard Zero-Width Space (ZWSP) which has zero visual width on screen but occupies 3 bytes in UTF-8.
