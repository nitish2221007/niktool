Classless Inter-Domain Routing (CIDR)

Introduced in 1993 by RFC 1519, CIDR replaced rigid Class A/B/C address blocks with flexible variable-length subnetting (VLSM) to prevent IPv4 address exhaustion.

Private browser-based processing

All calculations and conversions run 100% locally in your browser. No personal data or numbers are ever transmitted or saved to external servers.

Frequently asked questions

Why are 2 IP addresses subtracted from total subnet hosts?

The first address is reserved as the Network Identifier, and the last address is reserved as the Subnet Broadcast Address.
