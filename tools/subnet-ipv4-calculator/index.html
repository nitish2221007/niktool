CIDR Subnetting Basics

Classless Inter-Domain Routing (CIDR) allocates IP addresses with variable-length prefix masks. In a /24 subnet (255.255.255.0), the first IP is reserved for the Network ID and the last IP for Broadcast, leaving 254 assignable addresses.

Frequently asked questions

Why are 2 addresses subtracted from total hosts?

The network address (all host bits 0) and the broadcast address (all host bits 1) are reserved and cannot be assigned to network interfaces.
