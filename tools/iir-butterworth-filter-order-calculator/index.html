How to use IIR Butterworth Analog & Digital Filter Order Calculator

  1. Enter passband edge frequency F_p in Hz.
  2. Enter stopband edge frequency F_s in Hz (F_s > F_p).
  3. Enter maximum allowed passband ripple attenuation A_p in dB (e.g. 1.0 dB or 3.0 dB).
  4. Enter minimum required stopband attenuation A_s in dB (e.g. 40 dB to 60 dB).
  5. Inspect minimum integer filter order N and asymptotic high-frequency roll-off slope in dB/octave.
