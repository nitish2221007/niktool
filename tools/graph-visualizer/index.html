Graph Basics

A graph G = (V, E) consists of vertices (nodes) and edges (connections). Graphs model networks, maps, dependencies, and more.

BFS vs DFS

  1. BFS (Breadth-First Search) — explores neighbors level by level using a queue. O(V+E). Finds shortest path in unweighted graphs.
  2. DFS (Depth-First Search) — explores as deep as possible before backtracking using a stack/recursion. O(V+E). Used for cycle detection, topological sort.

FAQ

Directed vs Undirected?

This visualizer uses undirected edges (bidirectional). Directed edges have a one-way arrow.
