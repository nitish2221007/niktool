How to use 1D Discrete Kalman Filter State Estimate & Measurement Update (K_k) Calculator

  1. Enter model prior state estimate prediction $hat{x}_{ ext{prior}}$ (e.g. from odometry / physics propagation).
  2. Enter prior estimate error variance $P_{ ext{prior}}$ ($sigma^2$).
  3. Enter new noisy sensor measurement reading z (e.g. from GPS / LiDAR / sonar).
  4. Enter sensor measurement noise variance R ($sigma_v^2$).
  5. Inspect optimal Kalman Gain $K_k$, updated posterior state estimate $hat{x}_{ ext{post}}$, and reduced error variance $P_{ ext{post}}$.

Frequently asked questions

What happens when sensor noise R approaches zero?

As $R o 0$, Kalman Gain $K_k o 1.0$, meaning the filter trusts the measurement completely and sets $hat{x}_{ ext{post}} = z$.
