RFC 5952 IPv6 Representation Rules

RFC 5952 standardizes IPv6 text representation: leading zeroes in each 16-bit field MUST be suppressed, hexadecimal characters MUST be lowercase, and the longest contiguous run of zeros MUST be compressed into "::".
