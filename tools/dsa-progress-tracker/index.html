How to track your DSA journey

  1. Go through the default topic checklist (Arrays → Advanced DP).

  4. Your progress auto-saves — close the tab and come back anytime.

FAQ

Is my data uploaded anywhere?

No. Everything is stored in your browser's LocalStorage. Clearing browser data will reset progress.

What order should I learn DSA?

Arrays → Strings → Linked Lists → Stacks/Queues → Trees → Graphs → Heaps → Tries → DP → Greedy → Advanced topics.
