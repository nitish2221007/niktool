Frequently asked questions

What is Forward Error Correction (FEC)?

FEC adds redundant parity bits to transmitted data so receivers can detect and correct channel errors without retransmission.

What is Coding Gain?

Coding gain is the reduction in required Eb/N0 in dB achieved by coded transmission compared to uncoded transmission at the same BER.

Why are Turbo codes and LDPC codes used in LTE/5G?

Turbo and LDPC codes approach within ~0.1 dB of the theoretical Shannon channel capacity limit.
