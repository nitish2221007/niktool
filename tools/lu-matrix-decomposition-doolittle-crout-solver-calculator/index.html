Myrick H. Doolittle 1878 Matrix Factorization Method

Factoring $A = LU$ decomposes Gaussian elimination into two fast triangular substitution sweeps ($Ly = b$ and $Ux = y$), enabling high-speed solving of multiple load cases in finite element structural engineering software.

Frequently asked questions

Why is LU decomposition faster than finding matrix inverse A^(-1)?

LU decomposition requires $sim rac{2}{3}n^3$ operations, whereas finding matrix inverse requires $sim 2n^3$ operations and has inferior numerical stability.
