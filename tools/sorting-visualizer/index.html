Algorithm Complexities

  1. Bubble Sort — O(n²) avg/worst, O(n) best, O(1) space
  2. Selection Sort — O(n²) all cases, O(1) space
  3. Insertion Sort — O(n²) avg/worst, O(n) best, O(1) space
  4. Merge Sort — O(n log n) all cases, O(n) space
  5. Quick Sort — O(n log n) avg, O(n²) worst, O(log n) space

FAQ

Which sorting algorithm is fastest?

For general-purpose sorting, Merge Sort and Quick Sort (O(n log n)) outperform O(n²) algorithms on large datasets. Quick Sort is often fastest in practice due to cache locality.

Is Insertion Sort ever useful?

Yes! For nearly-sorted or very small arrays (n < 20), Insertion Sort outperforms O(n log n) algorithms due to low constant factors.
