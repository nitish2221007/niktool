  4. Inspect total economic output Y, factor marginal products ($MPK, MPL$), and Returns to Scale ($alpha + eta$).

Paul Douglas & Charles Cobb 1928 Macroeconomic Production Function

The Cobb-Douglas production function models how capital and labor inputs combine under diminishing marginal returns; when $alpha + eta = 1$, doubling all inputs exactly doubles output, establishing the benchmark constant returns to scale neoclassical growth model.

Frequently asked questions

What happens if alpha + beta is greater than 1?

The firm enjoys economies of scale (Increasing Returns to Scale), meaning output grows faster than proportional input growth.
