How to use RSA Asymmetric Public & Private Key Encryption Math Calculator

  1. Enter two prime numbers p and q (e.g. 61 and 53).
  2. Enter public exponent e (e.g. 17 or 65537, must be coprime to φ(n)).
  3. Enter plaintext integer message M (M < n).
  4. Inspect generated RSA modulus n = p · q, Euler totient φ(n), calculated private key d, and encrypted ciphertext C = M^e mod n.

Ron Rivest, Adi Shamir & Leonard Adleman 1977 RSA Cryptosystem

RSA security rests on the computational asymmetry of prime factorization: multiplying two 1024-bit primes to create n takes microseconds, but factoring n back into p and q to find private key d requires billions of compute years.

Frequently asked questions

Why is e = 65537 the standard public exponent in RSA?

65537 has only two set binary bits, making modular exponentiation M^e mod n extraordinarily fast via repeated squaring (only 17 multiplications).
