How to use Capital Asset Pricing Model (CAPM) Expected Return Calculator

  1. Enter risk-free rate $R_f$ (e.g. 10-year government bond yield).
  2. Enter company/stock Beta coefficient $eta$ (measure of volatility relative to the broad market).
  3. Enter expected long-term broad stock market return $E[R_m]$ (typically 9-10% for S&P 500).
  4. Inspect expected asset return (Cost of Equity in corporate WACC calculations).

Treynor, Sharpe, Lintner & Mossin's 1964 CAPM

CAPM establishes the fundamental financial pricing rule: the expected return of an asset equals the risk-free rate plus a risk premium proportional to its systematic market beta covariance ($eta = ext{Cov}(R_i, R_m)/ ext{Var}(R_m)$).

Frequently asked questions

What is the expected return for a stock with Beta = 1.5, Rf = 4%, and Market Return = 10%?

E[R] = 4% + 1.5 × (10% - 4%) = 4% + 9% = 13.0%.
