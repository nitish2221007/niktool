Mathematical & Theoretical Formulas

This calculator evaluates performance using the following core formulas:

$$\displaystyle Q = \sqrt{\frac{R_{\text{high}}}{R_{\text{low}}} - 1}, \quad L = \frac{R_{\text{low}} \cdot Q}{\omega}, \quad C = \frac{Q}{\omega \cdot R_{\text{high}}}$$

Worked Example

Frequently asked questions

Why is impedance matching essential in RF design?

Impedance matching maximizes power transfer and eliminates standing wave reflections (VSWR = 1:1).

What is an L-network?

An L-network uses two reactive components (one series, one shunt) to match unequal resistive impedances at a single frequency.

Can an L-network match any complex impedance?

Yes, by absorbing load/source reactances into the calculated L and C components.
