Algorithm Comparison

  1. BFS — unweighted, guarantees shortest path, explores uniformly
  2. DFS — unweighted, no shortest-path guarantee, explores deeply
  3. Dijkstra — weighted, guarantees shortest path, expands lowest-cost node first
  4. A* — weighted + heuristic, usually fastest, uses Manhattan distance to guide search

FAQ

Why does A* explore fewer nodes than Dijkstra?

A* uses a heuristic (estimated distance to goal) to prioritize nodes closer to the target, pruning unpromising directions.

Is Dijkstra a special case of A*?

Yes — Dijkstra is A* with a heuristic of 0 for every node.
