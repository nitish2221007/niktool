What is a Stack?

A stack is a linear data structure that follows Last-In-First-Out (LIFO). The last element pushed is the first one popped. Think of a stack of plates.

Operations

  1. Push(x) — add element to top — O(1)
  2. Pop() — remove top element — O(1)
  3. Peek()/Top() — view top without removing — O(1)
  4. isEmpty() — check if stack is empty — O(1)

Real-world uses

Where are stacks used?

Undo/Redo in editors, function call stack, browser back button, expression evaluation, DFS traversal, and parenthesis matching.
