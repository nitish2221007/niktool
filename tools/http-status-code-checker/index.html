IETF RFC 9110 HTTP Semantics Standard

HTTP status codes standardize communication between web clients, proxies, CDNs, and backend servers across 5 distinct classes (1xx Informational, 2xx Success, 3xx Redirection, 4xx Client Error, 5xx Server Error).

Frequently asked questions

What is the difference between 401 and 403?

401 means "Unauthenticated" (login credentials missing/invalid); 403 means "Forbidden" (you are logged in, but lack administrative permission).
