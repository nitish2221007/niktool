How to use Abbe Number & Optical Glass Chromatic Dispersion Calculator

  1. Enter helium yellow d-line (587.6 nm) refractive index $n_d$.
  2. Enter hydrogen blue F-line (486.1 nm) refractive index $n_F$.
  3. Enter hydrogen red C-line (656.3 nm) refractive index $n_C$.
  4. Inspect calculated Abbe number $V_d$ and glass classification (Crown vs Flint).

Ernst Abbe's 1870 Optical Quality Metric

High Abbe number ($V_d > 55$, Crown glass) indicates low chromatic aberration color fringing; pairing high-Abbe crown glass with low-Abbe flint glass forms color-corrected achromatic camera lenses.

Frequently asked questions

What is the Abbe number of standard N-BK7 glass?

Standard Schott N-BK7 optical glass has $n_d = 1.5168$ and an Abbe number of $V_d = 64.17$.
