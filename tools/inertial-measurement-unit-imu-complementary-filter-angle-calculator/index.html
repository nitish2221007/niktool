How to use IMU Sensor Fusion Complementary Filter Orientation Angle Calculator

  1. Enter prior orientation tilt angle $ heta_{k-1}$ in degrees.
  2. Enter gyroscope angular rotation rate $omega_{ ext{gyro}}$ in $^circ/ ext{s}$.
  3. Enter IMU sensor sampling loop time step $Delta t$ in seconds (e.g. 0.010 s for 100 Hz).
  4. Enter raw accelerometer inclination angle $ heta_{ ext{accel}} = ext{atan2}(A_y, A_z)$ in degrees.
  5. Enter filter weighting parameter $alpha$ (typically 0.96–0.98).
  6. Inspect noise-filtered fused orientation angle $ heta_k$.

Lightweight Digital Sensor Fusion Filter

High-pass filters gyroscope integration (eliminating slow DC gyro integration drift) and low-pass filters accelerometer readings (eliminating high-frequency motor vibration noise) with minimal CPU cycles on 8-bit/32-bit microcontrollers.

Private browser-based processing

All calculations and conversions run 100% locally in your browser. No personal data or numbers are ever transmitted or saved to external servers.

Frequently asked questions

Why is a complementary filter used over a full Kalman filter?

It requires only 2 additions and 2 multiplications per loop update, executing $100 imes$ faster than an Extended Kalman Filter (EKF) matrix inversion.
