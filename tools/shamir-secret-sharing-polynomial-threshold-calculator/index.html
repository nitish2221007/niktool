Adi Shamir 1979 Polynomial Threshold Cryptography

A polynomial of degree $k-1$ is uniquely determined by k distinct points; Shamir's scheme provides information-theoretic security ($H(S | k-1 ext{ shares}) = H(S)$), safeguarding Bitcoin multisig vault keys and nuclear launch authorization codes.
