Richard Hamming 1950 Forward Error Correction (FEC)

By strategically interleaving 3 parity bits at powers-of-two positions ($1, 2, 4$), the binary syndrome value directly points to the exact integer index of the corrupted bit ($S = 5 implies ext{bit 5 is flipped}$), enabling real-time hardware error correction in ECC computer RAM.

Frequently asked questions

How many errors can Hamming (7,4) correct vs detect?

Standard Hamming (7,4) has a minimum Hamming distance $d_{min} = 3$, allowing it to correct any single-bit error ($t = 1$) or detect up to 2-bit errors.
