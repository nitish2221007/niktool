Convolutional Weight Sharing & Translation Invariance

Convolutional layers reuse small spatial kernels across the entire image, drastically reducing parameter count compared to fully connected layers while capturing spatial hierarchical features.

Frequently asked questions

What is Same Padding in deep learning?

Same padding ($P = (K - 1) / 2$ with stride $S=1$) preserves the exact input spatial resolution in the output ($O = W$).
