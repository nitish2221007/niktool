What is Big-O Notation?

Big-O notation describes the upper bound of an algorithm's running time as the input size grows. It helps developers compare algorithm efficiency independent of hardware or language.

Complexity Classes (Best → Worst)

  1. O(1) — Constant time (array access by index)
  2. O(log n) — Logarithmic (binary search)
  3. O(n) — Linear (single loop)
  4. O(n log n) — Linearithmic (merge sort, heap sort)
  5. O(n²) — Quadratic (nested loops, bubble sort)
  6. O(2ⁿ) — Exponential (recursive Fibonacci)
  7. O(n!) — Factorial (TSP brute force)

Frequently asked questions

Why do we ignore constants in Big-O?

Big-O focuses on growth rate. O(2n) and O(n) grow at the same rate — only the shape of the curve matters for large inputs.

What is the difference between Big-O, Big-Ω, and Big-Θ?

Big-O is the worst-case upper bound, Big-Ω is the best-case lower bound, and Big-Θ is a tight bound when both match.
