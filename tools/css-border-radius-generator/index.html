Understanding the 8-Value Border Radius Slash Syntax

CSS border-radius supports a slash syntax (e.g. 60% 40% 70% 30% / 40% 30% 70% 60%) where values before the slash define horizontal radii, and values after the slash define vertical radii for asymmetric organic curvature.
