How to use Rectangular Waveguide Cutoff Frequency & Mode Calculator

  1. Enter rectangular waveguide broad wall dimension $a$ in mm (e.g., 22.86 mm for WR-90 / X-band).
  2. Enter narrow wall dimension $b$ in mm (e.g., 10.16 mm).
  3. Enter mode indices $m$ and $n$ (default TE10 dominant mode).
  4. Enter operating frequency in GHz.
  5. Click Process to compute cutoff frequency $f_c$ and guide wavelength.

Mathematical & Theoretical Formulas

This calculator evaluates performance using the following core formulas:

$$\displaystyle f_c = \frac{c}{2} \sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}, \quad \lambda_g = \frac{\lambda}{\sqrt{1 - (f_c/f)^2}}$$

Frequently asked questions

What is the dominant mode in a rectangular waveguide?

The TE10 mode has the lowest cutoff frequency of all modes in a rectangular waveguide.

What happens when operating frequency f < fc?

The electromagnetic wave attenuates exponentially without propagating (evanescent mode).

What is WR-90 waveguide?

WR-90 is a standard X-band waveguide with inner dimensions 0.90 x 0.40 inches (22.86 x 10.16 mm) covering 8.2 - 12.4 GHz.
