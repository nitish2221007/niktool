Inverted Hydrometer API Scale

API gravity is inversely related to density: lighter crude oils with high gasoline/diesel fractions have higher API gravity numbers (> 31.1 °API) and float readily on water.

Frequently asked questions

What is the API gravity of water?

Pure water has a specific gravity of 1.000, which equals exactly 10.0 °API.
