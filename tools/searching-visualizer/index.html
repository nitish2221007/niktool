Linear vs Binary Search

  1. Linear Search — checks each element sequentially. O(n) time, works on unsorted data.
  2. Binary Search — halves the search space each step. O(log n) time, requires sorted data.

FAQ

When should I use Binary Search?

When data is already sorted and you need fast lookups. For n = 1,000,000, binary search needs only ~20 comparisons vs 1,000,000 for linear.

Why does the array auto-sort for Binary Search?

Binary Search requires a sorted array. The tool sorts automatically so you can focus on the algorithm.
