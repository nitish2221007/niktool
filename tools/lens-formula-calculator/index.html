How to use Lens Formula Calculator

  1. Choose which quantity to find: focal length, image distance, or object distance.
  2. Enter the two known values.
  3. Click Process to solve using 1/f = 1/v - 1/u, including magnification.

Key Features & Privacy

The tool solves the lens equation for the selected variable and also computes magnification m = v/u. Enter values using the Cartesian sign convention described in your textbook, and the calculator will handle the arithmetic. Everything runs locally.

Common Use Cases

Class 10 students use it for the Light chapter to verify ray-optics numericals and understand the relationship between u, v, and f.
