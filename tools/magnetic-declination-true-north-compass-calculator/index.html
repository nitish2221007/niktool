  1. Enter handheld magnetic compass bearing in degrees (0° to 360°).

  4. Inspect corrected True Geodetic North map heading for wilderness navigation.

NOAA World Magnetic Model (WMM) Corrections

Because Earth's magnetic north pole drifts continuously over time in northern Canada and Siberia, navigation charts provide annual magnetic variation rates to calibrate compass bearings against true geodetic north.
