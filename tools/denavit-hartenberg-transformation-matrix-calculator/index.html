How to use Denavit-Hartenberg (DH) 4x4 Robot Kinematics Transformation Calculator

  1. Enter joint angle theta (rotation about z-axis) in degrees.
  2. Enter link offset distance d (translation along z-axis) in mm.
  3. Enter link length a (translation along x-axis) in mm.
  4. Enter link twist angle alpha (rotation about x-axis) in degrees.
  5. Inspect the computed 4x4 homogeneous transformation position coordinates (X, Y, Z).

Jacques Denavit & Richard Hartenberg 1955 Convention

DH parameters provide a minimal 4-parameter standard convention to represent spatial relationships between consecutive joint axes on serial robotic manipulators.

Frequently asked questions

What is the difference between standard and modified DH parameters?

Standard DH places the coordinate frame at the joint output axis, whereas modified (Craig) DH places the origin at the joint input axis.
