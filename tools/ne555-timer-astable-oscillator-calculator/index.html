Signetics NE555 Timer Operation

In astable mode, capacitor C charges through (R₁ + R₂) to ⅔ Vcc and discharges through R₂ into the Pin 7 discharge transistor down to ⅓ Vcc, producing continuous clock pulses with zero external trigger.

Frequently asked questions

Why is standard 555 duty cycle always greater than 50%?

Because capacitor charging path includes both R₁ + R₂, while discharge path only includes R₂; adding a bypass diode across R₂ allows duty cycles below 50%.
