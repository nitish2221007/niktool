Binary Search Tree Rules

In a BST, every node's left child is smaller and right child is larger. This gives O(log n) average search/insert/delete.

Traversals

  1. Inorder (LNR) — visits nodes in sorted ascending order
  2. Preorder (NLR) — root first, used for tree copying
  3. Postorder (LRN) — children first, used for tree deletion
  4. Level Order — BFS, visits level by level

FAQ

What happens with sorted input?

Inserting sorted values creates a degenerate (linked-list shaped) tree with O(n) operations. Use AVL or Red-Black trees for guaranteed balance.
